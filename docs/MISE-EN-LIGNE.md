# PASSION IV — Mise en ligne

## 1. Finaliser le contact
Renseigner le lien WhatsApp réel dans `index.html`.

Format :
`https://wa.me/33XXXXXXXXX`

## 2. GitHub Pages
1. Ouvrir le dépôt `FABIEN8284/passion-iv-v4`.
2. Settings → Pages.
3. Deploy from a branch.
4. Branch : `main`.
5. Folder : `/ (root)`.
6. Enregistrer.
7. Tester l'URL créée sur ordinateur et mobile.

## 3. Domaine
Après validation du site GitHub Pages :
1. choisir / acheter le domaine ;
2. l'ajouter dans GitHub Pages ;
3. créer le fichier `CNAME` ;
4. configurer les DNS ;
5. activer HTTPS ;
6. vérifier l'adresse publique.

## 4. Sortie de ChatGPT Sites
Ne couper l'ancien hébergement qu'après validation du site GitHub Pages, du contact WhatsApp et du domaine.
